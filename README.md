# Sleep-Quality-predictor


The Sleep Detection System is a Python-based machine learning project that predicts sleep quality based on lifestyle factors such as sleep hours, stress level, screen time, exercise, caffeine intake, and awakenings.

This project uses machine learning algorithms such as Logistic Regression, Random Forest, Decision Tree, and Support Vector Machine (SVM) to classify sleep quality as Good, Average, or Poor. It provides a simple graphical user interface (GUI) built using Tkinter, allowing users to enter their details and view the predicted sleep quality.

Technologies Used:Python, Tkinter, NumPy, Matplotlib, Scikit-learn.

Objective:To predict sleep quality using machine learning and help users understand how lifestyle habits may influence their sleep.
